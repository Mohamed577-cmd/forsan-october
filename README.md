# فرسان القراءة في نصر أكتوبر

منصة تفاعلية عربية (RTL) ترافق بحثًا مدرسيًا بعنوان **فرسان القراءة في نصر أكتوبر**. صُممت لتقديم قراءة بصرية وتحليلية في حرب أكتوبر 1973، مع فصل المحتوى والمصادر عن مكوّنات الواجهة.

## التشغيل محليًا

```bash
npm install
npm run dev
```

بعد ذلك افتح الرابط الذي يعرضه Vite في الطرفية.

## بناء نسخة الإنتاج

```bash
npm run build
```

ينتج أمر البناء مجلد `dist` الجاهز للنشر.

## النشر على Netlify

1. ارفع المشروع إلى مستودع Git أو اسحبه إلى Netlify يدويًا.
2. في إعدادات البناء استخدم الأمر `npm run build`.
3. اضبط مجلد النشر على `dist`.
4. ملف `netlify.toml` الموجود في المشروع يضيف إعدادات البناء وSPA fallback تلقائيًا.
5. بعد النشر، راجع روابط المصادر النهائية قبل مشاركة الرابط مع لجنة التحكيم.

## QR CODE

1. انشر الموقع على Netlify أولًا.
2. انسخ رابط الإنتاج النهائي، وليس رابط `localhost`.
3. أنشئ رمز QR من رابط الإنتاج.
4. ضع رمز QR في الورقة البحثية أو لوحة العرض.

## تعديل المحتوى

كل النصوص القابلة للتحرير موجودة في ملفات البيانات، دون الحاجة لتعديل مكوّنات التصميم:

| الملف | ما يمكن تعديله |
| --- | --- |
| `src/data/topics.js` | بيانات الطالب والمدرسة، المحاور، العبارات التحليلية، وبطاقات الخطط والتأثير. |
| `src/data/timeline.js` | مراحل الخط الزمني والتفسير وعلاقة كل مرحلة بالمحاور. |
| `src/data/mapData.js` | أسماء طبقات الخريطة ووصفها ومفتاح الخريطة. |
| `src/data/sources.js` | المصادر، نوعها، ملخصها، سبب استخدامها، وروابطها. |

## إضافة روابط المصادر

افتح `src/data/sources.js`، ثم استبدل قيمة `url: '#'` برابط المصدر المراجع. لا توضع الروابط داخل مكونات React؛ ستظهر تلقائيًا في بطاقات المراجع عند إضافة الرابط.

## ملاحظات منهجية

- الخريطة تمثيل بصري مبسط لأغراض العرض والتحليل، وليست خريطة عسكرية دقيقة.
- المصادر النظرية في محور الحرب النفسية مخصصة لشرح المفاهيم، ولا تُستخدم لتوثيق وقائع أكتوبر مباشرة.
- راجع تفاصيل التواريخ والوقائع والروابط مع المصادر الأصلية قبل العرض النهائي.
